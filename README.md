# Azure Cove Villas

A single-page Next.js villa-resort landing page.

## Project structure

```text
src/app/             # App Router routes, root layout, and global styles
src/components/      # Reusable client and presentation components
src/lib/site.ts      # Site copy, image URLs, and external links
public/              # Local static assets when they are added
```

## Development

```bash
npm install
npm run dev
```

The current photography uses remote Unsplash image URLs defined in `lib/site.ts`.
